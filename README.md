# 🧠 All India Villages API

## 📌 Project Overview

This project processes and serves Indian village data using Python, MySQL, and Node.js.

## ⚙️ Tech Stack

* Python (Data Cleaning & Processing)
* MySQL (Database)
* Node.js + Express (Backend API)

## 🚀 Features

* Fetch villages data
* Filter villages by state
* Search villages by name
* Cleaned large dataset (lakhs of records)

## 📊 Data Processing Steps

1. Merged multiple Excel files using Python
2. Cleaned data (removed nulls, duplicates, extra characters)
3. Converted CSV → MySQL database
4. Built REST API to access data

## ▶️ How to Run the Project

1. Install dependencies:
   npm install

2. Start server:
   node server.js

3. Open browser:
   http://localhost:3000

## 🔗 API Endpoints

* `/villages`
* `/villages/state/:state`
* `/search/:name`
